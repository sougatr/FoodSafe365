# FoodSafe365 — Sprint 18 Guided Operational Checks

## Purpose
Make each daily operational check understandable to an ordinary restaurant employee/supervisor without requiring HACCP knowledge.

## Guided check structure
Each applicable check now presents:
1. WHY — why the check matters
2. WHAT — exactly what the employee should look for or do
3. STANDARD — the applicable FSSAI reference or FoodSafe365 operational requirement
4. SOURCE — source/traceability link
5. NOW CHECK — Yes / No / Not applicable or a measurement
6. FoodSafe365 result and next action

## Personal hygiene example
The personal hygiene check now prompts the supervisor to look at hair/head covering, nails, clean work clothes/apron, gloves where required, handwashing, prohibited behaviours and illness/wounds that should prevent food handling.

## Pest and waste example
The pest/waste check now prompts checks for visible pest signs, cleaning of surfaces and floors after food preparation, free-flowing drains, grease/cockroach traps where provided, regular waste removal, protected/covered waste bins and possible pest entry points.

## Regulatory handling
The UI distinguishes an FSSAI reference from a FoodSafe365 operational requirement. Temperature values are presented as source-specific references and are not automatically treated as HACCP critical limits.

## Verification
The problematic verification screen remains intentionally unchanged. This sprint focuses on onboarding → personalised controls → understandable daily operational checks.
