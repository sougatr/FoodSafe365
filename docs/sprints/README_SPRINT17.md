# Sprint 17 — Personalised Daily Check Plan

This sprint connects the Sprint 16 onboarding/control-plan experience to a simplified operational daily-check workflow.

Key pages:
- `/onboarding` — restaurant → processes → equipment → generated plan
- `/checks` — personalised daily checks
- `/checks?control=TEMP-STORAGE` — direct entry to one generated control when needed
- `/actions` — existing corrective actions

Verification is deliberately unchanged.
